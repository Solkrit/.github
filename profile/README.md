## ⚡ About Us

**Solkrit** (formerly known as *SolderLab*) is an engineering-driven electronics product development studio based in Bengaluru, India. We take hardware ideas from concept to deployable product. We design the circuit, write the firmware, build the enclosure, assemble the prototype, and coordinate manufacturing—as one connected, cohesive process rather than disjointed handoffs.
